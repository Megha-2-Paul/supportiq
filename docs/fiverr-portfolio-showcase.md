## Recommended portfolio title

**SupportIQ — Python NLP Ticket Classification & Analytics Dashboard**

## Portfolio description

Built SupportIQ, an end-to-end customer support ticket classification prototype for a banking-services scenario. The project combines a TF-IDF and Logistic Regression intent-classification pipeline with a FastAPI backend and an interactive Streamlit dashboard.

The application is designed to help demonstrate how unstructured support messages can be organized into intent categories, accompanied by a suggested support department and an explainable, rules-based priority recommendation. It also includes batch CSV/Excel processing, local prediction history, analytics, and model evaluation reporting.

**Highlights**
- NLP intent classification using the public Banking77 benchmark
- Python, Pandas, Scikit-learn, TF-IDF, and Logistic Regression
- FastAPI REST endpoints for single and batch predictions
- Streamlit dashboard for ticket analysis and operational insights
- CSV/Excel batch processing and downloadable results
- SQLite-based local prediction history
- Automated tests, GitHub Actions, Docker configuration, and technical documentation

**Important scope note:** This is a portfolio prototype, not production banking software. Banking77 does not provide sentiment or priority labels; sentiment is optional and unconfigured by default, while priority is a transparent keyword heuristic. Model metrics should only be added after running the training script and reviewing its generated report.
